Compiler diversity / backend independence

A second path from Rust source to machine code.

Ferraxis is an independent Rust compiler implementation built around its own frontend, semantic analysis, intermediate representation, and backend interfaces — without relying on rustc internals or requiring LLVM.

The operating alloy

Built for a compiler ecosystem with more than one path.

Rust has an exceptional reference compiler. Ferraxis explores what becomes possible when an independently engineered implementation can prove its own assumptions, choose its own backends, and carry the language forward with a separate architectural spine.

01 / CORRECTNESS

Correctness first

Behavior is earned through explicit evidence, not compatibility hacks or accidental implementation details.

02 / PORTABILITY

Portable by design

Backend interfaces stay independent from convenience, keeping future targets open.

03 / SEMANTICS

Specification authority

When sources disagree, Ferraxis follows a documented hierarchy of semantic authority.

04 / EVIDENCE

Assumptions exposed

Differential tests and semantic records make the path inspectable, repeatable, and honest.

Architecture / signal path

From source to output, every stage has a place.

First executable slice

Inspect the signal yourself.

Ferraxis is in Phase 0: compiler foundation. The first executable slice can store source, track spans, emit diagnostics, and dump a small deterministic token stream.

ferraxis / token probeREAD_ONLY
$ cargo run -p ferraxis -- --emit=tokens path/to/input.rs
